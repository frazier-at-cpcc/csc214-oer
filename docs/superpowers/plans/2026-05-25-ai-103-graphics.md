# AI-103 Graphics Generation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce the 15 missing/stale figures, renumber the 7 cross-chapter figures into clean document-order numbering, and delete the 13 orphaned figures, so the AI-103 textbook renders with correct, consistent graphics and the Antora build reports zero missing images.

**Architecture:** Hybrid generation. Text-bearing figures (diagrams, flows, matrices, dashboards, annotated panels) are authored as self-contained **HTML/CSS** and captured to PNG with a headless-browser script at the existing figure canvas (2752×1536). Figures whose content is *photographic/generated imagery* (the image-generation/editing figure and the sample images embedded in vision figures) use **AI image generation** for the raster, composited inside an HTML frame so labels stay crisp. File moves/renames and `image::` reference updates are deterministic per the master mapping in §B.

**Tech Stack:** HTML/CSS, Playwright (Chromium, via a small Node script), an AI image-generation MCP tool, Antora 3.1 for build verification, git for moves.

**Source of truth:** the content branch `ai-103-realignment` (PR #2), `graphics-manifest.md` (dispositions), and the content spec `docs/superpowers/specs/2026-05-25-ai-103-realignment-design.md` §8. Work continues on branch `ai-103-realignment`.

## A. Conventions

**Canvas:** every figure PNG is **2752×1536** (matches the existing 44). Light background, generous margins.

**Style guide (for HTML figures)** — derived from the existing figures' described aesthetic so new diagrams rhyme with surviving AI-gen art. Use this exact CSS in every HTML figure (paste as an inline `<style>`):

```css

  --bg:#f7f9fc; --panel:#ffffff; --ink:#1f2933; --muted:#52606d;
  --line:#cbd5e1; --blue:#2563eb; --teal:#0d9488; --orange:#ea7317;

  --blue-bg:#e8f0fe; --teal-bg:#e6f7f4; --orange-bg:#fdeede; --green-bg:#e7f6ec; --red-bg:#fdecec;
}
*{box-sizing:border-box;font-family:"Segoe UI",system-ui,-apple-system,sans-serif;}
html,body{margin:0;}
#fig{width:2752px;height:1536px;background:var(--bg);color:var(--ink);
  padding:96px 120px;position:relative;}
.fig-title{font-size:62px;font-weight:700;margin:0 0 16px;}
.fig-sub{font-size:34px;color:var(--muted);margin:0 0 56px;}
.box{background:var(--panel);border:3px solid var(--line);border-radius:20px;
  padding:32px 36px;font-size:34px;line-height:1.25;box-shadow:0 6px 18px rgba(15,23,42,.06);}
.label{font-size:30px;color:var(--muted);}
.tag{display:inline-block;border-radius:999px;padding:8px 22px;font-size:28px;font-weight:600;}
.arrow{height:6px;background:var(--line);position:relative;}

  border-top:14px solid transparent;border-bottom:14px solid transparent;}

```

Header pattern for every HTML figure: a single `<div id="fig">` containing `<h1 class="fig-title">` + optional `<p class="fig-sub">` + the diagram body. Keep ALL text inside `#fig` (the capture targets that element). Colors: blue = generative/Foundry, teal = tools/services, orange = caution/edit, green = success/safe, red = unsafe/error, purple = agents.

**HTML render harness** — `graphics/capture.mjs` (created in Phase 0). It loads an HTML file and screenshots `#fig` to a PNG at native 2752×1536.

**AI image-gen tool:** load via `ToolSearch` query `select:mcp__mcp-image__generate_image` (and `select:mcp__plugin_playwright_playwright__browser_navigate` etc. only if the Node script is unavailable). Generate landscape raster at the largest supported size; downscale/crop into the HTML frame.

**Working dir:** author HTML/JS under `graphics/` (committed — it's the figure source). Output PNGs go to `modules/ROOT/images/ch{NN}/`.

```js
import { chromium } from "playwright";
import path from "node:path";
const [,, htmlFile, outPng] = process.argv;
if (!htmlFile || !outPng) { console.error("usage: node capture.mjs <html> <out.png>"); process.exit(1); }
const browser = await chromium.launch();
const page = await browser.newPage({ viewport: { width: 2752, height: 1536 }, deviceScaleFactor: 1 });
await page.goto("file://" + path.resolve(htmlFile));
const el = await page.$("#fig");
if (!el) { console.error("no #fig element in " + htmlFile); process.exit(2); }
await el.screenshot({ path: outPng });
await browser.close();
console.log("wrote " + outPng);
```
