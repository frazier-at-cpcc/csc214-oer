AI-103 Vision Capabilities

Four capability areas — each with distinct input, output, and use case

Capability Typical Input Output Best For
Multimodal Understanding
vision chat / VQA 		Image + text prompt Captions, visual Q&A, alt-text Flexible visual reasoning — describe, answer questions about, or generate accessibility text for any image
Image Generation & Editing
DALL-E / Designer 		Text prompt + optional reference media / mask New or edited images Creating marketing visuals, product mockups, inpainting to change or remove objects
Content Understanding
document + video intelligence 		Image, video, or document (PDF / scan) Structured fields, markdown, JSON Extraction at scale — invoices, forms, medical records, video transcripts, slide decks
Responsible AI Layer
safety filters & policy 		Any visual content Filtered or policy-checked output; violation reports Safety compliance, brand protection, anti-injection defense — applied on top of all other capabilities

Understanding which capability to use is the first step in every AI-103 vision scenario.
